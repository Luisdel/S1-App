# Seguridad

No publiques vulnerabilidades, credenciales, tokens ni archivos
`google-services.json` en issues o pull requests. Para reportar un problema de
seguridad, utiliza un aviso privado de GitHub en lugar de hacerlo público.

Si no tienes disponible esa opción, contacta con los mantenedores mediante los
canales privados de la organización e incluye una descripción, pasos para
reproducir el problema, impacto y una posible mitigación. No subas secretos
reales como prueba; usa valores ficticios.
