# Código de conducta

Esperamos una participación respetuosa, inclusiva y profesional. No se
aceptan acoso, ataques personales, discriminación ni la publicación de
información privada.

Los problemas de conducta pueden comunicarse de forma privada a los
mantenedores del repositorio. Se revisarán de buena fe y se podrán aplicar
medidas proporcionales, incluida la moderación de contribuciones.
